# electricONtrol

Proyecto presentado en el hackathon eHACKMORELOS 2024: prototipo de control y monitoreo con Arduino y una aplicación web.

## Contenido

Todo el código está en `eHACKMORELOS2024/`:

| Carpeta | Descripción |
|---|---|
| `ArduinoProyecto/` | Sketch de Arduino y diagrama del circuito |
| `Simulacion/` | Simulación en Wokwi del circuito |
| `Cuernavaca 2024/` | Aplicación web con Node.js y Express (servidor, modelo de usuario, notificaciones por correo) |
| `Cuernavaca_Python_2024/` | Versión en Python con Flask (rutas, modelos, panel) |
| `presentacion/` | Presentación del proyecto en PDF |

## Stack

| Capa | Tecnología |
|---|---|
| Hardware | Arduino, simulación en Wokwi |
| Backend | Node.js, Express / Python, Flask |
| Frontend | HTML, CSS y JavaScript |

## Estado

Archivado. Proyecto de hackathon (2024), realizado en equipo, sin mantenimiento.
